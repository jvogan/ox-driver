# Changelog

## 1.0.0

- Add the guarded `pi-ox` root and mandatory `pi-child` launcher.
- Add `power`, `edit-only`, and `review-only` child profiles.
- Add direct, user-scope `pi-lead` and `pi-agent` orchestration with normal,
  team, and solo modes.
- Add package provenance, setup, sandbox, privacy, recovery, and acceptance
  guidance for the reviewed Ox Alpha route.
- Add an isolated Pi installer that enforces the completed npm shrinkwrap
  without replacing the user's raw Pi installation.
- Record Pi 0.84.3 as the initial reviewed harness version and keep raw Pi
  updates independent.
